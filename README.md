🎨 Design Features

- 🌀 **Modern Gradient Theme**  
  Menggunakan kombinasi warna biru muda dan hijau toska  
  *(#38dbf8 → #4cf0ac)* untuk memberikan kesan futuristik dan bersih.

- 🧊 **Glassmorphism Navbar**  
  Navbar transparan dengan efek **blur (backdrop-filter)** yang menambah kesan modern  
  dan tetap kontras terhadap latar belakang halaman.

- 🎞️ **Smooth Animations & Neon Glow**  
  Setiap tombol dan elemen memiliki animasi halus serta efek **neon glow**  
  untuk menciptakan tampilan yang interaktif dan dinamis.

- 🧱 **Card-based Project Layout**  
  Bagian “Project” menggunakan desain berbasis **card** dengan bayangan lembut (shadow)  
  dan efek hover agar setiap proyek terlihat menonjol serta mudah dibaca.

- 📱 **Responsive Grid System**  
  Desain web menyesuaikan secara otomatis untuk tampilan di **desktop, tablet, maupun smartphone**,  
  memastikan kenyamanan pengguna di semua ukuran layar.

- 🖱️ **Interactive Hover Effects**  
  Efek transisi lembut ketika pengguna mengarahkan kursor ke tombol, card, atau tautan,  
  menambah pengalaman interaktif tanpa mengganggu tampilan utama.

- 🌈 **Gradient Footer Section**  
  Footer menggunakan kombinasi warna gelap dan teks kontras dengan nuansa biru keunguan  
  untuk menjaga konsistensi tema elegan di seluruh halaman.
